# 第八批：教学流程试行交接

日期：2026-10-21。分支：feature/member-d。用户已明确同意按教学模型提案在 D 分支试行，总分暂不汇总。本批为 local/test 试行闭环，ED01–ED20 仍待模型冻结。

## 已实现

- 原成果任务创建者将本人已入库成果明确授权给教师；教师建立独立标准快照，不修改科研成果。撤销来源授权阻止新增标准/发布，已冻结作业继续使用既有教学数据。
- 教师创建课程、班级和真实学生成员，激活课程后发布作业。发布时固定标准版本、独立数据集、评分版本、截止时间、答案开放时间和次数上限。
- 学生显式新建每次练习；读取页面不会创建草稿。给定命题专项仅暴露给定命题，完整案例只提供范围原文与指南标签，不提供标准切割。
- 学生保存本人要素与 S/A/J/M/I 关系（含嵌套），复用 B 类型选择器、C 关系验证/图示。提交后保留独立不可覆盖的作答、评分快照；重练新建记录。
- 学生仅在本人已提交且到达开放时间后读取标准、专项评分和教师反馈。教师只能读取自己课程；管理员无隐含教学数据权限。班级成员撤销后立即阻止学生读取旧结果。
- 复用 C 五种关系/图专项评分。课程总分始终 null，完整案例边界/要素评分待定。教师反馈追加留存，不覆盖历史。
- 写入使用事务、幂等键及适用的 If-Match；校验截止、次数、旧版本和并发提交；审计失败整体回滚。

- 后端 191 项测试，0 失败、0 错误；含教学工作流 16 项及 C 评分器 8 项。
- 前端类型检查与生产构建通过。
- `scripts/verify-member-d-teaching.py` 在回环地址创建命名验收数据，验证正确专项 100 分、错误类型扣分、开放前不泄露、完整案例待定、次数上限、越权阻断、新标准不改变旧作业。`--verify` 重启后逐项比较历史结果和标准快照。
- 浏览器实测教师页面与学生“新建→关系编辑→保存图示→提交→待开放结果”；另检查开放后的 100 分与双图比对。
- 既有科研闭环、JSON/XLSX/PNG/SVG 已归档文件、自动任务回归通过，原 F1 内容摘要不变。真实数据库备份保存在忽略的 backend/target 内，未清库。

联验发现科研参与项数组顺序不一定等于 ordinal；适配层按 ordinal 排序后交给 C 评分器，并新增乱序回归。当前算法版本为 D-snapshot-v2；作业与成绩元数据的算法版本一致。旧规则不可执行时拒绝新练习/提交，不默默换规则。修复前的本地试验课程/成绩保留，算法版本可在比对页核查，不应作为正式成绩。

最新可核查样例 ID 见 `21-teaching-acceptance.json`。联验完整快照只在忽略目录 backend/target，未保存认证令牌。
