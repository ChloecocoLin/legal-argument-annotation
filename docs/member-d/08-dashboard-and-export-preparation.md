## U08 统计口径与适配边界

响应严格保持冻结的五个整数字段和六字段信封、meta=null，无自增字段或额外列表。

| 字段 | 本地联调口径 |
| --- | --- |
| guideCount | ADMIN 的指南版本按 guideId 去重；创建者仅计本人任务绑定的指南，不能把版本数冒充指南数 |
| documentCount | ADMIN 文书总数；创建者本人任务关联文书按 ID 去重 |
| taskCount | ADMIN 全部任务；创建者仅 ownerUserId=当前用户的任务 |
| pendingReviews | 可见案例按 ID 计数：未 COMPLETED、没有 IN_DATABASE 最终版、至少 max(2,N) 名不同作者的有效来源版本；已撤回和已退回版本不计，历史快照不重复计数 |
| autoQueueCount | 可见任务案例中的 QUEUED/RUNNING 自动任务数量，COMPLETED/FAILED/CANCELLED 不计 |

访问同时要求 ADMIN/TASK_CREATOR 与 TASK_OVERVIEW。每次请求重新认证和检查权限。page 为正整数，聚合无分页内容，兼容传入合法 page 而始终 meta=null。共享文档只声明 scope?:string，未定义取值和范围；本批省略 scope，显式传入任何 scope 均返回 VALIDATION_ERROR，避免把任意字符串解释为越权范围。上述口径和 scope 语义需 A/B/D 联调确认，但不影响已冻结响应结构。

DashboardData 是正式聚合读取端口；LocalDashboardData 仅 local/test 且 !prod，使用现有依赖存储、D 版本与最终版记录。生产需 A/B/自动化工作进程提供权威数据源适配器，没有退回本地数据的实现。不调用 B 当前演示数据填充值，不输出固定“完成率/一致率”。

## 导出开发适配边界

GET /api/local/member-d/export-preview 仅在 local/test 且 !prod 存在，不是公开 EX01。需要 ADMIN/TASK_CREATOR + EXPORT_CREATE；创建者仅本人任务。先按身份筛任务，再筛 IN_DATABASE，之后才读取冻结内容。输出最小文书/指南元信息、计数和动态字典解析的前五行。只读事务，不写审计、下载记录、文件或业务状态。

生产构建不调用本地端点；尚无确认的正式预览 DTO 时显示待接入，不从测试数据悄悄回退。记录页面只有界面框架和基础角色提示，没有读取真实导出记录的接口；正式记录授权必须以后端 EX03/EX04 为准。

原型多格式勾选与当前 EX02 单个 format 冲突，页面首批使用单选，保留格式卡片外观。JSON/XLSX 目前仅配置预览，PNG/SVG 显示待接入；核心文本、UTF-16 位置、结构化参与项、动态字典和来源是必备数据，不能通过选项移除。元数据展示名可以配置，不移除来源身份引用。
