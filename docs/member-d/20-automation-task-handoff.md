- 候选保持 PENDING_HUMAN_REVIEW；两份实际标注分配只读同一候选，审核状态不会共享改写。没有采纳/修改/拒绝或写人工草稿的入口，X/N、草稿、标注版本及最终来源不受自动完成影响。
