# 成员 D：集成版使用体验修复

基线：`origin/integration/latest`（268da55）；修复分支：`fix/member-d-integration`。

## 页面

- 成果、审计、导出和教学去掉分支、评审等开发提示，改为当前用户下一步；保留真实的环境权限限制。
- 审计主筛选为姓名、任务名、本地日期，默认今天及之前六天，UUID 收入高级筛选。请求转换为 UTC 日起止，后端权限判断后再进行姓名筛选，不改写原始审计事件。
- 管理工作台读取现有导出记录 API 展示最近五条；错误、加载、空记录分别显示，可到导出中心或指定记录。
- 成果详情为本人任务创建者提供「授权给教师」，进入教学授权表单并预选该最终版。教学按创建班级、授权、建立并发布标准、发布作业推进。没有成果时不创建假样例。
- 学生结果和比对页移除未定综合总分，保留关系/图专项分。
- 自动标注明确为本地测试，创建按钮使用「创建测试任务」，读取失败不再一直显示读取模型配置；缺少测试配置时禁止创建。人工候选审核仍由 B 的工作台接口接入，本次没有模拟接受候选。

## 查询与并发

- 对象编号查询使用 `(object_kind, object_id)` 主键。
- 关联编号筛选先在 SQL 缩小返回范围，再解析并校验 JSON；任务列表先按本人所有或参与的任务缩小范围，任务内案例、切割统计、导出候选先按任务/案例查询。
- Map 兼容层整类读取由逐行 N+1 查询改成一次查询；返回对象仍通过原事务写入。
- 审计对象和时间筛选下推到 SQL，保留逐条授权。
- 未修改写入锁顺序、版本冲突、幂等或令牌策略；未删除陈晓空草稿或写入现有业务数据库。

关联编号目前仍保存在 JSON 中，SQL 预筛选减少传输与反序列化，但不等同于完整的关联字段索引或数据库分页。正式数据量扩大时应通过增量迁移提取关联列并建立索引；本次不更改尚未冻结的文书模型。
